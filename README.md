# StudySprint AI

Production-quality Next.js demo app for rapid exam preparation.

## Quick Start

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Stack

- Next.js App Router + TypeScript
- Tailwind CSS
- Framer Motion
- Recharts
- React Hot Toast

## Pages

- `/` landing page
- `/dashboard` student command center
- `/prep` emergency prep mode
- `/tools` AI study tools tabs
- `/quiz` timed quiz with score review + confetti
- `/flashcards` animated flashcard drills
- `/chat` AI doubt assistant demo
- `/profile` student profile + progress chart

## Demo Notes

- Runs with local mock data only (no auth, no DB, no paid APIs).
- Designed for live laptop demos: dark glassmorphism UI, smooth transitions, and keyboard-friendly interactions.
